# Contributing to PathWise

Thanks for helping. PathWise stays calm, clear, and honest — same for contributions.

## Before you start

1. Read the short notes in [`AGENTS.md`](./AGENTS.md).
2. Skim the Contributing section in [`README.md`](./README.md).
3. Open an issue first for larger changes so we can align on scope.

## How to contribute

1. Fork the repo and create a focused branch.
2. Match existing patterns in `src/`. Prefer small diffs.
3. Do not commit `.env.local` or secrets. Use `.env.example` as the template.
4. Server-only secrets must **not** use the `VITE_` prefix.
5. Run `npm run lint` and `npm run build` before opening a PR.
6. Fill out the pull request template — say what changed and why.

## Decision-map UX

Decision maps are the product. Keep exploration UX calm, clear, and honest about uncertainty. Avoid noisy UI or overpromising outcomes.

## Issues

- Bugs → use the bug report template
- Ideas → use the feature request template
- Security → see [`.github/SECURITY.md`](./.github/SECURITY.md) (do not file public issues for vulnerabilities)
